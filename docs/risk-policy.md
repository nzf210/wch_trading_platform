# Risk Policy

1. No risk check = no order.
2. No active subscription = no order.
3. Emergency stop active = no order.
4. Invalid API permission = no order.
5. Withdrawal permission detected = reject account.
6. Max daily loss exceeded = pause bot.
7. Max position size exceeded = reject order.
8. Duplicate idempotency key = reject order.
9. Paper mode is default.
10. Live mode requires explicit activation.
